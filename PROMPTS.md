# My prompts

Every prompt I've written to Claude Code for my MoLab projects, in order, in my own words with
my typos left in. I'm keeping this to track how my prompting changes over the semester. Git
history shows each time I add to it.

- **Exact wording:** nothing is rewritten. I only removed the tags around text I pasted in
- **Left out:** automatic system messages, and prompts about clearing space on my Mac, because
  they aren't about my projects
- **Changed:** my email address is replaced with `[my Google account]`
- **Times:** New York time
- **AI use:** Claude Code pulled these from my saved session history and drafted the notes for
  each week from my prompts. `[placeholder: say what I reviewed and changed]`
